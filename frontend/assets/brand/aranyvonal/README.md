# Aranyvonal Hair Studio demo arculat

A mappa a publikus demo vizuális assetjeit tartalmazza. Ezek **szándékosan verziózott, publikus fájlok**, ezért Gitbe és productionre is kerülhetnek.

- `logo.svg` – demó logó/favikon forrás
- `hero.svg` – hero vizuál
- `services/*.svg` – szolgáltatáskártyák illusztrációi

Az assetek kizárólag fiktív demó márkához készültek, nem tartalmaznak valós személyt vagy ügyféladatot.
